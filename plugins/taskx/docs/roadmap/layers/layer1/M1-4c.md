# M1.4c — Dev subset focus via debug tag (operator switch seam) 🟡


Intent:

- Keep iteration throughput when rendered task display is capped.
- Let operators enforce a working subset when switching milestone focus.
- Preserve default ranking behavior when debug subset mode is disabled.

Constraint:

- This is a dev-only, opt-in mode.
- Default behavior remains unchanged when the mode is off.
- The filter is a visibility seam, not a ranking-policy replacement.

Deliverables:

- Define a dedicated debug subset mode with explicit enable/disable control.
- Use a namespaced tag token for subset selection: `#taskx-debug`.
- Filter displayed tasks to the tagged subset only when debug subset mode is enabled.
- Provide a visible indicator in the rendered block when debug subset mode is active.
- Ensure deterministic fallback behavior when the subset is empty or absent:
  - debug mode remains visibly active,
  - feed falls back to baseline (non-subset) output.

Implementation order (files to touch):

1. 🟡 `docs/taskx-glossary.md` and `docs/taskx-naming.md` (if needed)
   - Contract the debug subset concept, tag token semantics, and stability expectations.

2. 🟡 `src/entry/render-defaults.ts` and `src/entry/render.ts`
   - Add dev-only opt-in toggle wiring for debug subset mode.

3. 🟡 `src/core/pipeline/stage-collect.ts`
   - Apply tagged-subset filtering behind the opt-in seam without changing base policy.
   - If no tagged tasks are found, return the baseline collected set unchanged.

4. 🟡 `src/ui/feed/render-feed.ts`
   - Render a clear active-mode indicator when debug subset mode is enabled.

5. 🟡 `tests/` (T1)
   - Add deterministic coverage for:
     - mode disabled => default behavior unchanged,
     - mode enabled with tagged tasks => subset-only output,
     - mode enabled with no tagged tasks => baseline feed output with debug
       indicator still visible,
     - active-mode indicator presence.

Success criterion:

- Operators can switch focus by adding/removing `#taskx-debug` on tasks.
- When mode is enabled, rendered output follows the tagged subset contract.
- When mode is enabled and no tags are present, baseline feed output remains
  available while debug mode indicator stays visible.
- When mode is disabled, TaskX output is identical to baseline behavior.
- UI clearly signals when debug subset mode is active.
