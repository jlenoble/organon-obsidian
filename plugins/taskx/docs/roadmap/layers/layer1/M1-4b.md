# M1.4b — Dev debug mirror for rendered block state (follow-up, implicit) 🟡

Intent:

- Improve debugging feedback loops by persisting the rendered block state to disk
  during development.

Constraints:

- The mirror is debug-only and must not change ranking/recommendation policy.
- The mirror is gated by a dedicated boolean flag.
- Default behavior is enabled in dev mode.
- Mirror output path for this loop is `plugins/taskx/temp/task_feed.md`.

Deliverables:

- Add an explicit debug-mirror toggle in entry/runtime defaults.
- Mirror the rendered block output to `plugins/taskx/temp/task_feed.md` when
  the toggle is `true`.
- Keep mirror content deterministic and sanitized for local debugging use.
- Ensure mirror writes are best-effort and do not break block rendering.

Implementation order (files to touch):

1. 🟡 `src/entry/render-defaults.ts`
   - Add the dedicated debug mirror toggle default (dev-enabled).

2. 🟡 `src/entry/render.ts`
   - Wire mirror behavior from runtime options to the render flow.

3. 🟡 `src/adapters/obsidian/` (new mirror writer helper as needed)
   - Write/update `plugins/taskx/temp/task_feed.md` safely when enabled.

4. 🟡 `tests/` (T1)
   - Add coverage for mirror enabled/disabled behavior and write safety.

Success criterion:

- After a task change and rerun, `plugins/taskx/temp/task_feed.md` is created
  or updated when debug mirror is enabled.
- Mirrored content matches the rendered TaskX block text for the same run.
- Disabling the toggle stops mirror writes without changing feed behavior.
